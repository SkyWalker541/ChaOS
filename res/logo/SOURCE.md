# Where this art came from

The ChaOS logo ("Handheld burst"): a small handheld with pixels breaking loose
from its screen, beside the name in pixel letters with OS in orange.

Original artwork made for ChaOS on 2026-11-06. It contains no third-party
images, fonts or characters: the handheld and every letter are drawn pixel by
pixel in `genlogo.py`, which is the only source. Every file in `out/` is
redrawn from it with `python3 genlogo.py`, scaled by whole numbers with no
smoothing.

The handheld is a generic one, not a drawing of any particular device.

Colours: ground #17151C, cream #F4EAD5, orange #FF7A2F, cyan #39C5D6,
screen #26323C, outline #3A3446.
