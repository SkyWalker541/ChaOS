# The ChaOS Pixel Burst theme's fonts

- `pixel.ttf`: **Pixelify Sans** by the Pixelify Sans Project Authors, from Google Fonts
  (https://github.com/google/fonts/tree/main/ofl/pixelifysans), SIL Open Font
  License 1.1 (OFL-pixel-pixelify.txt). The variable font as published, read at its default
  weight.
- `pixel-head.ttf`: **Silkscreen** by the Silkscreen Project Authors (Jason Kottke), from Google Fonts
  (https://github.com/google/fonts/tree/main/ofl/silkscreen), SIL Open Font
  License 1.1 (OFL-pixel-silkscreen.txt).

Both unmodified. Used only while the ChaOS Pixel Burst theme is on.
