# The ChaOS Pixel Burst theme's fonts

- `pixel.ttf`: **Pixelify Sans** by the Pixelify Sans Project Authors, from Google Fonts
  (https://github.com/google/fonts/tree/main/ofl/pixelifysans), SIL Open Font
  License 1.1 (OFL-pixel-pixelify.txt). The variable font as published, read at its default
  weight.
- `pixel-head.ttf`: **Tiny5 SC** (the small-caps cut of Tiny5) by the Tiny5
  Project Authors (Stefan Schmidt), from https://github.com/Gissio/font_Tiny5
  (also on Google Fonts), SIL Open Font License 1.1 (OFL-pixel-tiny5.txt).
  Headings, and the stand-in for any letter Pixelify Sans does not have:
  Tiny5 covers Latin with every accent (Vietnamese too), Greek, Cyrillic and
  Armenian.

Both unmodified. Used only while the ChaOS Pixel Burst theme is on.
